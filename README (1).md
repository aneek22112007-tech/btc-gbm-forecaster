## Three concepts — how they're implemented

### 1. No peeking
```python
for i in range(warmup, len(closes) - 1):
    history = closes[:i+1]   # indices 0 … i — bar i+1 is invisible
    actual  = closes[i+1]    # revealed AFTER prediction
```
The slice `closes[:i+1]` makes it structurally impossible to leak future data.

### 2. Volatility clustering
```python
recent_vol = np.std(log_ret[-vol_lookback:], ddof=1)  # last 20 bars only
```
Short window means the model widens its range immediately after a violent hour
and narrows it during calm stretches — matching Bitcoin's actual behaviour.

### 3. Fat tails — Student-t
```python
nu, mu_t, _ = student_t.fit(fit_data, floc=0)
sim_returns = student_t.rvs(df=nu, loc=mu_t, scale=recent_vol, size=n_sim)
```
Bitcoin log-returns have empirical ν ≈ 3–5 (much heavier tails than a Gaussian).
Using a normal distribution would systematically under-cover rare large moves.

## Metrics reference

| Metric | Target | Interpretation |
|--------|--------|---------------|
| `coverage_95` | ≈ 0.95 | Fraction of hours where actual fell inside the predicted range |
| `mean_width` | as low as possible while coverage ≈ 0.95 | Tighter = better model |
| `mean_winkler_95` | lower = better | Combines accuracy + tightness in one number |
